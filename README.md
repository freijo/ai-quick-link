# AI Quick Link ⚡

**AI Quick Link** ist eine Chrome-Erweiterung, die Ihren Browser-Workflow nahtlos mit KI-Tools verbindet. Markieren Sie Text auf einer beliebigen Webseite und senden Sie ihn mit einem einzigen Klick oder Tastendruck direkt in das Eingabefeld Ihres bevorzugten KI-Chats.

## 🌟 Implementierte Funktionen

Basierend auf der aktuellen Version bietet die Erweiterung:

* **Direkter Versand:** Markierter Text wird übernommen und ein neuer Tab beim gewählten Anbieter geöffnet.
* **Unterstützte Anbieter:** ChatGPT, Claude (Anthropic) und Google Gemini.
* **Duale Steuerung:**
    * **Tastenkombination:** Standardmäßig `Alt+A` (im Browser konfigurierbar).
    * **Kontextmenü:** Rechtsklick auf markierten Text -> "An KI senden 🚀".
* **Automatisches Einfügen:** Der Text landet direkt im Chat-Eingabefeld der Zielseite.
* **Prompt-Vorlagen (Templates):** Definieren Sie Text, der automatisch *vor* (Prefix) und *nach* (Suffix) dem markierten Text eingefügt wird (z.B. "Fasse zusammen:" ... "in Stichpunkten").

---

## ⚙️ Konfiguration & Nutzung

Nach der Installation finden Sie das **blaue "AI"-Icon ⚡** in Ihrer Erweiterungsleiste. Klicken Sie darauf, um das Einstellungsmenü zu öffnen.

### Das Options-Menü

1.  **KI-Assistent wählen:**
    Nutzen Sie das Dropdown-Menü, um festzulegen, welcher Dienst (z.B. Claude oder ChatGPT) geöffnet werden soll.

2.  **Tastenkombination (Hotkey) verwalten:**
    * Das graue Feld zeigt die aktuell aktive Tastenkombination an (Standard: `Alt+A`).
    * Klicken Sie auf den Button **"Ändern"**, um das native Chrome-Menü für Tastenkürzel zu öffnen und eine eigene Kombination festzulegen.

3.  **Prompt-Vorlagen definieren:**
    * **Prompt davor (Prefix):** Text, der dem markierten Inhalt vorangestellt wird (z.B. Arbeitsanweisungen für die KI).
    * **Prompt danach (Suffix):** Text, der angehängt wird (z.B. Formatierungswünsche).
    * *Hinweis:* Lassen Sie die Felder leer, um nur den markierten Text zu senden.

*Alle Einstellungen werden automatisch gespeichert, sobald Sie sie ändern.*
